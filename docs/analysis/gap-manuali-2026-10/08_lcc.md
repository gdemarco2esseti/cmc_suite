# Gap 08 - Emblemsvag, Life-Cycle Costing using ABC and Monte Carlo (Wiley 2003)
Source read in full (ch.1-9, App. A-B, glossary). Chapter refs: Ch1..Ch9, AppA, Gloss. Weight = core / advanced / niche.
Convention: DC = direct costs/BOM; FC = fixed/expense-vs-cost/capacity-provided; DIFF = what-if/alternatives comparison; CENTERS = resource hierarchy/system boundary/SBU.
