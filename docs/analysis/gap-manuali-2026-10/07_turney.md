# Turney, Common Cents (rev. ed. 2005) - functional capabilities for an ABC/ABM system

Source: /Users/2st/Downloads/Manuali/ABC_Turney_Common_Cents/ABC_Turney_Common_Cents.md (read in full, ch. 1-15 + glossary; index skimmed). Chapters cited as Ch.N.

| Area | Capability | Detail: inputs -> calculation/formula -> output | Source | Weight |
|---|---|---|---|---|
| ABC | Model the two-dimensional ABC cross (cost assignment view + process view) | Entities: resources, resource drivers, activities, activity cost pools/elements, activity drivers, cost objects (vertical); cost drivers + performance measures per activity (horizontal). Cost flows resources -> activities -> cost objects; nonfinancial info flows horizontally. Output: one model serving both costing and improvement | Ch.4, Ch.5 | core |
| CLASS | Classify resources by type and by effort vs non-effort | Resource = GL-derived cost element (salaries/benefits = effort; travel, supplies, utilities, depreciation = non-effort). Effort costs driven by time share; non-effort traced where records exist, else allocated | Ch.5, Ch.14 | core |
| CLASS | Classify activities by hierarchy level (unit / batch / product-service / customer) and by role (primary / secondary-enabling / core) | Attribute on activity: level determines allowed driver type (unit: DLH/machine hours; batch: runs, setups, moves; product: ECNs, part numbers, engineering hours; customer: orders, # customers). Core vs enabling for gov/non-profit; regulated vs unregulated tag for utilities | Ch.3, Ch.14 | core |
| ABC | Maintain an activity dictionary | Master list: ID, standard verb+noun name, definition, task list, source/site, process, subprocess. Enforce consistent naming across plants for benchmarking | Ch.5, Ch.14 | core |
| ABC | Support macro activities (two-tier activities) | Aggregate detail activities into a macro activity if same level, same driver, common purpose; strategic users see macro, improvement teams see detail. Roll-up of cost | Ch.14 | advanced |
| CENTERS | Group activities in activity centers (departmental, nested, on-demand) | Rule 1: departmental centers first (mirror org chart); Rule 2: build centers on demand from attributes (process, quality type, scorecard perspective); Rule 3: nested hierarchy (process > department > sub-center). Output: center report with activity costs, resources, performance data | Ch.5, Ch.14 | core |
| CLASS | Free-form attributes on activities/data for ad hoc reporting | Labels: value-added / non-value-added / gray; prevent-detect-correct (cost of quality); process membership; scorecard perspective; channel; regulated/unregulated; fixed/variable (set by user, not designer). Reports filter/group by attribute | Ch.3, Ch.14 | core |
| ALLOC | Reconstruct GL into ABC resource cost pools | Rule 1 combine related accounts (e.g. salaries+benefits+pension = personnel); Rule 2 decompose to department level; Rule 3 adjust uneconomic items (recompute depreciation on consumed basis, hold development costs in special account for life-cycle spreading); Rule 4 activity-based GL. Input GL trial balance by period/dept -> output resource pools by dept | Ch.14 | core |
| ALLOC | Assign resource cost to activities via resource drivers (tracing first, allocation last resort) | Effort: activity_cost_share = sum(person time% on activity x person salary weight) / dept total effort x dept personnel cost (e.g. 2/10 x 50% = 10% of $100,000 = $10,000). Optional salary-weighted version. Non-effort: direct measurement (supplies per activity, kWh by meter) or driver (floor space %, weighted $/sq ft). Output: cost elements per activity | Ch.5, Ch.14 | core |
| ALLOC | Flag each cost assignment as traced vs allocated | Metadata on every resource-driver line (traced = likely to disappear if activity eliminated; allocated = will not). Report share traced/allocated | Ch.14 | advanced |
| ALLOC | Assign enabling/secondary activity cost to the primary activities they support | Admin/HR/supervision activity cost distributed by relative time spent or headcount served to primary activities, then carried to cost objects with the primary activity. Optional: leave general-benefit activities (PR, charity) unassigned | Ch.3, Ch.14 | core |
| ALLOC | Allow weighted drivers and warn on arbitrary allocation | Support weighted cost per sq ft (clean room vs normal), alternative-driver sensitivity (e.g. 67/33 vs 50/50 split) so users see that allocation is not provable | Ch.14 | niche |
| ABC | Produce the bill of costs per activity | Per activity: list of cost elements by GL account/resource (salaries, benefits, postage, telephone...) with YTD actual, % actual vs budget; total = activity cost pool. Used to know which resources to remove/redeploy | Ch.5 | core |
| ABC | Compute activity cost pool and unit activity cost rate | cost pool = sum(cost elements); rate per driver unit = pool / driver volume (e.g. $333,500 / 667,000 boards = $0.50; $450,000 / 6,000 POs = $75/PO) | Ch.3, Ch.5 | core |
| DC | Define activity drivers (transaction-based and time-based) per activity | Driver catalogue: type (transaction/duration/intensity), level, measurement source (system table, timekeeping, manual), volume per cost object per period. Rule checks: matches activity level, correlates with consumption, minimal number (20-30 typical), encourages improvement, modest measurement cost, reuse existing data | Ch.5, Ch.14 | core |
| ABC | Assign activity cost to cost objects via activity drivers | cost object cost = sum over activities(driver quantity consumed x activity rate); product-level activity spread over units: cost/unit = product-level cost / volume (tooling $500 / 200 units = $2.50 vs $500/50 = $10) | Ch.3, Ch.5 | core |
| ABC | Support multiple cost-object types and hierarchies | Hierarchy products: part number/ingredient -> product -> family; customers: customer -> channel/market/territory/segment; also services, projects, contracts, orders, suppliers, accounts, highways. Costs roll up and slice by any dimension | Ch.5, Ch.10 | core |
| ABC | Cost at part-number level with bulk ETL data | Cost tens of thousands of parts (80,000 parts, 58 drivers at Stockham) using driver counts loaded from MRP/purchasing/shop-floor tables; compare to standard costs; feed make-or-buy | Ch.5, Ch.13 | advanced |
| ABC | Produce the bill of activities per cost object | For any product/service/customer: list of activities consumed, driver quantity, unit rate, cost, level, VA/NVA flag; total = ABC cost. Basis for goal seeking, quality cost per product, design costing | Ch.7, Ch.8 | core |
| ABC | Compute product/service profitability including non-manufacturing costs | Profit = revenue - ABC cost (manufacturing + selling/distribution/admin); show margin vs conventional standard cost side by side (e.g. $1.00 price, $0.67 std, $4.30 ABC mfg, $20.30 total). Report ABC cost as % of conventional | Ch.3, Ch.5 | core |
| ABC | Report customer profitability (cost to serve) | Customer P&L: sales - product costs (via bill) - support activity cost (orders x $50, support calls x $75, field engineering hours x $50). Include cost-of-capital charge optional (value added = net profit - capital charge on customer assets) | Ch.5, Ch.10 | core |
| ABC | Customer/supplier/product/channel profitability across millions of rows | Monthly run on order-line/shipment/invoice-line transactions; P&L by order line, customer, supplier, product, DC, shipment, segment; close within days of GL close (Percival: 400k orders, 600k shipments, 800k lines, 350 activities) | Ch.6, Ch.10 | advanced |
| KPI | Whale curve report | Sort customers (or products/suppliers) by profit desc; chart cumulative profit as % of total (peaks >100%, tail negative) | Ch.10 | core |
| KPI | 2x2 / quadrant segmentation reports | Revenue vs net margin quadrants (best, grow revenue, raise margin, worst); product volume vs profit quadrants (promote / reposition / cost-reduce / drop); stars / strong performers / question marks / opportunity groups with action prompts | Ch.8, Ch.10 | advanced |
| ABC | Customer/market segment grouping and per-order metrics | Group customers by segment, channel (electronic/mail/phone cost per order), order size; DVA per order by segment; minimum-order and unprofitable-small-order threshold analysis (orders < $50 unprofitable) | Ch.10 | advanced |
| ABC | What-if cost recovery tool for a customer | Inputs: unrecovered cost, scenarios (reduce small orders, bill perishable/refrigerated handling, increase sales). Output: $ recovered per lever, % sales increase needed to recover (e.g. $23K -> 20% sales growth) | Ch.10 | advanced |
| TDABC | Build time-based ABC (capacity cost rate) | cost per minute = monthly cost of resource group / practical capacity minutes; practical capacity = headcount x available minutes/person (e.g. 20 x 7,920 = 158,400 min, $80,000 -> $0.50/min); theoretical capacity = total paid time before breaks | Ch.6 | core |
| TDABC | Time equations as single activity driver | Activity time = base + sum(conditional extras), e.g. pick = 0.5 + 8.5 (hazardous) + 10.0 (oversize) minutes; cost = time x cost/min; evaluated per order line from ERP attributes -> few activities, millions of cost objects | Ch.5, Ch.6 | core |
| CAPACITY | Compute resources required vs available and unused capacity | required minutes = sum(volume x unit time) (8,000x15 + 2,000x10 + 1,000x5 = 145,000); utilization = required / practical capacity (92%); FTE equivalent (18.4 of 20); cost of resources available = cost of resources required + cost of unused capacity | Ch.6 | core |
| CAPACITY | Isolate idle-capacity cost from product cost (avoid death spiral) | Charge cost objects only for resources used (required x rate); keep unused-capacity cost as separate period line; do not reabsorb into remaining products | Ch.2, Ch.3, Ch.6 | core |
| CAPACITY | Define practical capacity and productivity per activity/resource class | Resource dictionary: skills, minutes per output, practical capacity %, activities performed; productivity rates replace percentage resource drivers | Ch.6, Ch.14 | core |
| CAPACITY | Load plant by profitability against activity capacity; detect bottlenecks | Production schedule/mix -> workload per activity via activity drivers (holes to drill -> drilling hours) -> compare to capacity -> bottleneck list -> adjust schedule or justify capex by savings (e.g. $300k) | Ch.9 | advanced |
| BUDGET | Activity-based budgeting from resource planning | Forecast outputs of cost objects -> derived activity volumes (1,000 installs x 5 POs = 5,000 POs) -> time/resources required -> cost of required resources -> compare to resources deployed -> adjusted plan and budget; scenario versions (mix, growth, new products) | Ch.6 | core |
| BUDGET | Run forward (planning) model in reverse | Replace cost assignment by productivity factors + output quantities + capacity per resource; compute resource requirements and cost for each scenario | Ch.12, Ch.14 | advanced |
| BUDGET | Performance budgeting / outcome-based spending plan | Link strategic goals, performance measures and resource plans; budget justified by service levels (GPRA style) | Ch.6, Ch.15 | advanced |
| FCST | Decision simulation on the activity model | Simulate cost/capacity impact of outsourcing, process improvement, new mandates, demand changes, redeployment; net revenue of extra funding (revenue collected - activity cost; "activity-based revenue") | Ch.6, Ch.8 | advanced |
| ABM | Activity analysis: value-added / non-value-added / gray classification | Per activity: VA (essential to customer), gray (essential to organization), waste; equivalent FTE and cost per class; % of cost that is waste; Pareto-rank significant activities (20% of activities = 80% cost) | Ch.7, Ch.8 | core |
| DC | Record cost drivers (causes of workload) per activity with chaining | Cost driver = event/factor determining volume/effort; link between activities: performance measure of upstream activity = cost driver of downstream (defect rate -> rework/purchase requisitions); internal vs external drivers | Ch.4, Ch.5, Ch.8 | core |
| KPI | Record performance measures per activity | Output volume, cost per output (cost pool/volume), elapsed time/cycle time, quality (error, rework, scrap rate, first-pass yield, returns); targets, trend, benchmark | Ch.4, Ch.5 | core |
| KPI | Benchmark activities internally and externally | Compare unit activity cost, error rate, cycle time across sites/periods/competitors/best practice; gap-to-best display (e.g. FPY 92% vs 95% sister vs 98% competitor) | Ch.5, Ch.7 | advanced |
| KPI | Cost-driver vs activity-cost trend chart | Plot driver quantity (e.g. # modifications) against activity cost over time to show relationship and lag of resource response | Ch.7 | advanced |
| KPI | Feed balanced scorecard / strategy map | Tag activities with scorecard perspective; supply activity-cost and customer-profit measures; targets per period vs actual; detect disconnects (activities with no goal, goals with no activities) | Ch.14, Ch.15 | advanced |
| ABM | Pareto analysis of activities and drivers | Rank activities by cost pool; group activity drivers by type (labor, material, setup, ECN, test, quality) and show % of cost assigned per group | Ch.8 | core |
| ABM | Goal seeking | Start from product bill of activities -> highlight high-cost activities and non-value-added ones -> list cost drivers -> actions to eliminate/reduce | Ch.8 | advanced |
| ABM | Cost-reduction simulation (what-if on drivers) | New driver quantities x unit rates for each alternative (e.g. C-part procurement: 1 PO + 12 invoices vs thousands); compare total cost per alternative; show activities eliminated | Ch.8 | core |
| ABM | Track resources freed and redeployed (cost reduction realization) | Compute unused/underused resources after improvement (hours/FTE x rate); redeployment decision log (grow, redeploy, remove); verify savings reach the P&L, not only capacity | Ch.7, Ch.10 | core |
| ABM | Improvement project prioritization and tracking | Project types (eliminate activity, substitute lower-cost activity, reduce resources, share/combine activities); expected savings from ABC; owners; realized savings vs target; 4 cost-reduction rules (reduce time, eliminate, select low-cost, share, redeploy) | Ch.7, Ch.9, Ch.15 | advanced |
| ABM | Storyboarding / value-analysis workshop support | Capture process activities, FTE per activity, VA flag, cost drivers, performance measures, selected key drivers, time freed and action plan per team | Ch.8 | niche |
| ABM | Strategic analysis: pricing floor and repricing | Bid price must exceed ABC cost; list products priced below ABC cost; price-up candidates; minimum order charge to recover order/batch activities | Ch.8, Ch.9 | core |
| ABM | Sourcing / make-or-buy and outsource-process analysis | Compare supplier price with ABC cost including hidden activities (ordering, expediting, handling, storage, quality, travel, kitting, tracking); part-level and process-level (cost per check processed) comparison | Ch.1, Ch.8 | advanced |
| ABM | Supplier cost-to-manage analysis | Activity cost of each added supplier / back-up supplier / per part; single vs multi-source what-if; supplier profitability | Ch.9, Ch.10 | niche |
| ABM | Competitor "reverse engineering" cost estimate | Estimate competitor activities from product design + annual report data and price accordingly | Ch.8 | niche |
| TARGET | Target costing | target cost = planned market price - required profit - distribution/non-mfg cost; compare design alternatives by building cost from activity driver rates; iterate until target met | Ch.8 | core |
| TARGET | Design cost guidelines / rule-of-thumb table | Store relative activity costs (SMT 1.0x, robot 3x, hand pre-solder 6x, post-solder 10x; ECN $2,500; test $3/board; unqualified vendor 3x) and show cost of design choices (layers, holes, size, part count) | Ch.8, Ch.9 | advanced |
| TARGET | Quote/bid costing from product characteristics | Build ABC cost for an RFQ from attributes (layers, holes, size) x driver rates; sales commission/incentive on ABC profit | Ch.9 | advanced |
| LCC | Life-cycle costing (development cost spread over expected lifetime volume) | Special life-cycle account: periodic LC cost per unit = LC cost / estimated lifetime volume ($20,000 / 10,000 = $2); balance recomputed with residual cost / residual volume; update estimates of volume and cost; replacement-cost depreciation | Ch.8, Ch.14 | advanced |
| LCC | Life-cycle phase profitability (prototype / production / service) | Cost per unit by phase (e.g. $562 vs $133) and total over life; decide on acquiring early, last-buy, handing off | Ch.9 | niche |
| LCC | Show cost committed during design vs incurred | Report awareness that 60-95% of lifecycle cost is committed in design (design-to-cost) | Ch.1, Ch.8 | niche |
| COQ | Cost of poor quality by activity, product and shift | Cost of defects = defect units x ABC cost accumulated to point of detection; attribute prevention/detection/correction; shift-end report, top-10 offenders Pareto by product (rework + scrap cost), cause and routing | Ch.9, Ch.14 | advanced |
| COQ | Cost of scrap/rework per product in the bill of activities | Scrap not free: costs of extra capacity, inspect, rework, returns visible per product; priority for quality projects | Ch.7, Ch.9 | advanced |
| DIFF | Compare ABC cost with conventional (standard/DLH-based) cost | Side-by-side per product: conventional = overhead rate x DLH (e.g. $120/DLH); ABC = activity drivers (e.g. $100/inspection hour); show variance %, overcosted/undercosted flag | Ch.2, Ch.3 | core |
| VAR | Actual vs budget by GL resource and cost element | Bill of costs shows YTD actual %, budget; monthly activity performance tracking vs plan; note: Turney criticizes DL efficiency/purchase-price variances as performance basis | Ch.5, Ch.2 | niche |
| FIN | Reconcile ABC to the general ledger | 100% of GL costs assigned in historical model (total conventional = total ABC; only distribution changes); non-GAAP economic adjustments tracked separately; separate unused capacity | Ch.3, Ch.14 | core |
| FIN | Handle time-period alignment (accrual vs cash, multi-year benefit) | Match payroll accruals to time card periods; account for resources benefiting multiple years via holding accounts | Ch.14 | niche |
| CAPACITY | Resource dictionary | Skills, capacity, productivity, activities performed per job position/equipment; link to HR/equipment systems | Ch.6, Ch.14 | advanced |
| OTHER | Data collection tools: effort analysis worksheet, questionnaires, timekeeping | Matrix people x activities with % time and driver column; pre-/post-interview questionnaires; web timekeeping by activity (day/week) feeding resource drivers | Ch.13, Ch.14 | core |
| OTHER | ETL from ERP/GL/payroll/inventory/purchasing/shop floor | Scheduled extract of GL by dept/period, time cards, driver counts (POs, receipts, setups, runs, moves, inspections, ECNs, orders, shipments, invoice lines) mapped to driver ids; hand-entry only for small drivers; monthly refresh | Ch.13, Ch.15 | core |
| OTHER | Model versioning, periods and scope switches | Run historical or forward-looking; whole period or part; subset of cost objects/activities/locations; single-period vs life-cycle; pilot -> sustained system; model update when activities/products change | Ch.12, Ch.15 | advanced |
| OTHER | Validation and data-quality checks | Check 100% cost assignment, driver volumes vs system totals, reasonableness vs past, review of model by interviewees; ABC accuracy balance (simple but not simpler) | Ch.10, Ch.14 | advanced |
| OTHER | Role-based access and web reporting of preformatted ABC reports | Managers query/slice model on web; preformatted reports by decision; users trained | Ch.12, Ch.15 | advanced |
| OTHER | ABC analytics (statistics/data mining on large models) | Forecasting, simulation, clustering (e.g. neural nets) to group customers/products by complexity factors and find profit drivers | Ch.10 | niche |
| OTHER | Project tooling for ABC implementation | Objectives, deliverables, scope, schedule (3-6 months), cost drivers of implementation effort, budget (internal+external) | Ch.12 | niche |
