## Rulings
1. Standard-mode "double count" is by design: cost_primo there is a per-unit standard reference, stamped direct lines stay in the overhead pool (Σ indirect = Σ final-centre residual). Standard×qty + variance is WP-03. Characterization test: standard mode with stamped direct lines → Σ cost_indiretto = Σ residual (2370 = Z 1770 incl. 570 direct + W 600), prime_cost_origin='standard'. Document in prime_cost_source help.
2. rate component total = unit_cost_complessivo. 3. used > practical → whole fixed pool charged, idle 0, never negative. 4. facts/lines manual, no cmc_mrp depends (AD-102).
5. Fallback (orchestrator, corrected): actual mode, product in scope with produced facts and no direct lines → cost_primo = standard_price × produced_qty, prime_cost_origin='standard_fallback' (0 if no produced qty; RM case cost_primo 0, flag standard_fallback). Flag values standard/actual/standard_fallback.

## Contract
- cmc.costing.run inputs (in _cmc_input_fields): prime_cost_source standard|actual (default standard); produced_measure_id M2o cmc.cost.driver (check_company, domain measure_kind='statistical'); capacity_basis actual|practical (default actual); markup_percent Float. Outputs: unabsorbed_cost Monetary (reset clears), capacity_ids O2m cmc.costing.capacity (in _cmc_result_fields). action_cmc_prefill_lines(): draft only (else UserError); replaces line_ids with one line per (final centre, product, allocation measure) = Σ actual facts (version empty) in period/company with centre and product cost object, restricted to product_ids if set; skip sums ≤ 0.
- cmc.costing.capacity (new, _inherit cmc.run.result.mixin, cascade): run_id, company_id related stored, currency_id, center_id, fixed_cost, variable_cost, capacity_practical, capacity_used, fixed_rate, fixed_charged, unabsorbed_cost. One row per final centre, practical basis only.
- cmc.costing.result: produced_qty, prime_cost_origin, unit_cost_primo/_industriale/_complessivo/_economico_tecnico/_variable/_fixed (digits "Product Price"), cost_variable, cost_fixed (= complessivo − variable), price_cost_plus (Monetary, currency-rounded). Methods _cmc_unit_cost_curve(volumes)->list[dict], _cmc_bid_check(price)->dict as in test docstrings.
- cmc.costing.quota: amount_fixed + amount_variable = amount; coefficient = centre amount charged ÷ centre driver base.
- cmc.costing.config: unit_amount Float; primo row source direct_lines|standard_price|standard_fallback.
- cmc.costing.simulate (TransientModel): result_id, currency_id, bid_price, volumes Char (comma-separated), non-stored outputs unit_full_cost, unit_variable_cost, margin, covers_full_cost, covers_variable_cost (from _cmc_bid_check); curve_line_ids → cmc.costing.simulate.line (wizard_id, quantity, unit_variable, unit_fixed, unit_cost) filled by action_cmc_curve().
- Engine: actual mode prime = stamped direct lines of product cost objects of run company per centre (one grouped read at centre×object×behaviour), subtracted from the centre pool; scope adds products with stamped direct cost. Variable pool = centre own variable cost (_cmc_cost_groups(behavior="variable")) minus stamped variable direct cost in actual mode; fixed pool = residual − variable pool (service allocations count as fixed). Practical: exactly one cmc.capacity.analysis of run company covering the period else ValidationError; single base + practical → ValidationError. Rates: one row per month covered, per result with produced_qty>0, 3 components, holder = existing cost object, _cmc_publish under CMC_RUN_STATE. Usage: _cmc_record_usage(closing_run_id).
- Performance: grouped reads only, cost objects resolved with one search (never created at compute), standard_price batch, batched creates, zero queries per product; engine sudo within company perimeter.
- Security: ACL capacity (user read, manager full), simulate + line (user+manager full); company rule on capacity.
