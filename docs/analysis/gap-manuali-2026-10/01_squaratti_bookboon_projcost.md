# Capabilities from: Squaratti (CdG per PMI), Bookboon (Process and ABC, Walther/Skousen), Project Cost Management (Frohnhoefer/Hassen)

Abbreviations in Source: SQ = Squaratti; BB = Bookboon Process & ABC; PCM = Project Cost Management. Note: SQ is a popular, non-technical booklet (no formulas); it gives the functional skeleton (business plan -> budget -> monthly monitoring -> forecast -> KPI -> product margin). BB covers process costing + ABC only. PCM covers project estimating, budget, EVM, cash flow, project selection.
