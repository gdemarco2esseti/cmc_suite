## Contract
- `cmc_utils`: `month_start(d)`, `month_end(d)`, `month_range(df, dt)` (ValueError if reversed), `phase_by_month(total, df, dt, rounding, weights=None)` → `{date: float}` via `spread()`; weights per calendar month, missing = 0, zero sum → ValueError.
- `cmc.plan.version` (`_inherit cmc.run.mixin`): `name`, `company_id`, `date_from`, `date_to` (ValidationError if to<from), `version_type` budget(default)/forecast/standard/simulation, `parent_id`, `assumption_ids` → `cmc.plan.version.assumption` (`version_id`, `name` req, `note`), `currency_id` (default company), `currency_rate` (default 1.0, >0). `_cmc_input_fields` = date_from, date_to, version_type, company_id, currency_id, currency_rate; `name` editable after approval. `action_approve()` = `action_compute()` with no results; approve/compute/reset → AccessError unless `group_cmc_manager`. `copy()` → draft child with `parent_id`, copies assumptions + planned facts + planned rates in batch; a cmc_user may copy (also from approved). `_cmc_to_company_currency(amount)`, `_cmc_months()`. Views relabel `done` as "Approved".
- `cmc.run.usage` (sudo-only writes): `consumer_model`, `consumer_id`, `origin_model`, `origin_id`, `company_id`. Mixin `_cmc_record_usage(origins)` (UserError without `CMC_RUN_STATE`); base `_cmc_check_no_dependents` blocks reset/unlink of an origin read by a computed consumer; consumer reset/unlink deletes its usages. Mixin `action_reset_to_draft` also deletes `cmc.rate` rows with origin = that run (sudo + sentinel). Existing overrides (e.g. `cmc_full_costing/models/cmc_closing.py`) keep calling `super()`.
- `cmc.cost.object`: `object_type` product/customer/supplier/project/unassigned, `res_model`, `res_id` (Many2oneReference), `company_id`; display_name from referenced record; no parent. `models.UniqueIndex` (object_type, res_model, res_id, company_id). `_cmc_ensure_objects(records, company=None, object_type=None)` (api.model, sudo inside) → recordset aligned with input, batch create, idempotent.
- `account.analytic.line.cmc_cost_object_id` m2o store index. Migration `cmc_base/migrations/19.0.1.3.0/post-migrate.py`, manifest 19.0.1.3.0, set-based, WARNING per unmappable value.
- `cmc.cost.driver` + `measure_kind` allocation(default)/statistical, `measure_type` transaction/duration/intensity, `source` manual(default)/feeder, `feeder_key` Char.
- `cmc.measure.quantity` (`_check_company_auto`): `driver_id`, `date` (normalised to 1st of month on create/write), `company_id`, `version_id`, `center_id`, `cost_object_id`, `quantity`, `feeder_key`; check_company on version/center/object. Planned fact inside version span (ValidationError); locked when version done (create/write/unlink UserError, even superuser). `models.Index` (company_id, date, driver_id, version_id). `_cmc_feeder_profiles()` → [] in base, bridges extend via super(). `_cmc_refresh_feeders(df, dt, company=None, keys=None)`: sudo, `_read_group` only, `_cmc_ensure_objects`, one batch create, replaces only actual facts of own key/company/month; query count independent of source rows. Cron `cmc_base.ir_cron_cmc_measure_feeders`.
- `cmc.rate`: `holder_model`, `holder_id`, `driver_id`, `cost_element_id`, `component` fixed/variable/total(default), `date` (month), `value`, `company_id` (= origin company), `currency_id` related, `origin_model`, `origin_id`. Unique index per T-2. `_cmc_publish(origin, rows)`: run origin needs sentinel (else UserError); version origin only while draft; approved-version rates immutable (UserError). `_cmc_lookup(holder, driver, on_date, origin=None, component="total", company=None)` → ≤1 row for the month; without origin only run rates, newest origin wins.
- `account.move.line` readers (cmc_account, api.model): `_cmc_revenue_read_group(company, df, dt, groupby=())` → rows `(*groups, revenue)`; `_cmc_gl_balance_read_group(company, df, dt, groupby=("account_id","date:month"))` → `(*groups, balance)`; `_cmc_gl_balances_at(company, date_to)` → `{account: balance}` (BS cumulative, P&L from fiscal-year start via `compute_fiscalyear_dates`). Gate: `env.su` or `group_cmc_user`, and company in `env.companies`, else AccessError; aggregation in sudo with `# why`. Revenue = `-sum(balance)` posted, account_type income/income_other, all move types.
- Bridge data: `cmc_mrp.cmc_measure_produced_qty` key `mrp_produced_qty` (done finished moves of MO +1; done unbuild consume moves `consume_unbuild_id` −1; byproducts excluded; done qty in product UoM). `cmc_account.cmc_measure_customer_invoice_lines` key `account_customer_invoice_lines` (out_invoice posted, display_type product, by partner, object type customer).
- Security: every new model global company rule `company_id parent_of company_ids`, NOT noupdate. ACL r,w,c,u: version/assumption/measure quantity user 1111 manager 1111; rate user 1110 manager 1111; cost object user 1000 manager 1110; run usage user 1000 manager 1000.
- Views (all `cmc_base/views/`): `cmc_plan_version_views.xml` (list/form/search, `action_cmc_plan_version`, `menu_cmc_plan_version` under `menu_cmc_sec_base`); `cmc_measure_quantity_views.xml` (editable list, pivot, search, `action_cmc_measure_quantity` under `menu_cmc_sec_base`); `cmc_rate_views.xml` (readonly list/search, `action_cmc_rate` under `menu_cmc_sec_analysis`); `cmc_cost_object_views.xml` (readonly list/search, `action_cmc_cost_object` under `menu_cmc_cfg_master`). Edit existing: new driver fields in `cmc_cost_driver_views.xml`; optional `cmc_cost_object_id` column in `account_analytic_line_views.xml`.
